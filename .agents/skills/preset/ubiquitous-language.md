# ubiquitous-language.md

Use when domain language is inconsistent.

Build shared terminology from code and request.

Identify:

- entities
- states
- actions
- business rules
- synonyms causing confusion

Create one preferred term for each concept.

Then use those exact terms in:

- code
- file names
- APIs
- tests
- discussion

Rename unclear terms when safe.
