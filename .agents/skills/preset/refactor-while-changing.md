# refactor-while-changing.md

Use whenever touching existing code.

Leave area better than found.

Look for:

- duplication
- confusing names
- mixed responsibilities
- long functions
- unnecessary nesting
- weak boundaries

Apply small safe improvements during delivery.

Do not perform unrelated rewrites.
